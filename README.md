# ClaudeSkill

This repository separates drafting guidance from final auditing so each skill loads only what the task needs.

| Skill | Use it for |
| --- | --- |
| `academic-outline` | Plan section order, paragraph roles, and page allocation without drafting prose |
| `academic-writing` | Draft and revise regular research papers, figures, tables, and captions |
| `academic-self-check` | Audit a near-final paper for claims, data, citations, visuals, layout, and submission risks |
| `survey-writing` | Build taxonomies and synthesize literature for surveys, reviews, and SoK papers |
| `rebuttal-craft` | Prepare concise, consistent responses to peer review |

Recommended sequence for a research paper:

1. Use `academic-outline` when the argument or section order is unsettled.
2. Use `academic-writing` while drafting and revising.
3. Use `academic-self-check` after major result updates and before submission.
4. Add `rebuttal-craft` only when responding to reviews.

Detailed examples and checklists live in each skill's `references/` directory and should be loaded only when relevant.
